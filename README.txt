# Dannywebmakers DWM

A responsive, multi-page website starter for a website-creation business.

## Included
- `index.html` — home page, services, process, FAQ and contact form
- `about.html` — how DWM makes websites and why clients should choose DWM
- `settings.html` — dark mode, large text, animation controls and reset
- `styles.css` — responsive visual design
- `script.js` — dynamic navigation, localStorage settings, animations, year and form validation
- `images/web-development.jpg` — supplied hero/background image

## Dynamic features
This is a front-end dynamic website. It uses JavaScript and browser local storage for settings and interactive behaviour. The enquiry form opens the visitor's email application; it does not send mail from a server.

## Publishing
Upload the entire folder to GitHub Pages, Netlify, or another static hosting service. Keep the `images` folder in the same location as the HTML files.

## Security note
The site uses basic client-side validation and avoids inserting user input into HTML. For a production application with accounts, payments, databases or server-side processing, add a secure backend, HTTPS, server-side validation, authentication controls where needed, security headers and appropriate data protection.
